# منصة أثر التعليمية (إدارة الصعيد)

لوحة تحكم إدارية متكاملة لإدارة الطلاب، متابعة حالات الدفع، توليد كود التفعيل وأكواد الباركود (QR Code) للكارنيهات، مع نظام فحص الصلاحية والإنذار التلقائي لفترة الـ 30 يوماً.

## مميزات النظام:
- تسجيل بيانات الطلاب الجدد وتتبع حالة الدفع.
- توليد وتنزيل أكواد الباركود الخاصة بالكارنيهات بصيغة QR.
- نظام إنذار ذكي لفترة صلاحية اشتراك الطالب (30 يوماً).
- لوحة تحكم سلسة لإدارة الحالات وتأكيدها أو حذفها.
- إرسال تقارير إدارية فورية عبر الواتساب.
